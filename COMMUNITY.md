## Adicionar sua implementação

Abra um pull request neste arquivo, na seção do ID correspondente. Inclua:

- Seu nome ou identificação pública preferida.
- Link para o repositório ou diretório da implementação.
- Linguagem utilizada.
- Uma descrição curta opcional: abordagem, descoberta, limitações ou trabalho em andamento.

Soluções parciais são bem-vindas quando identificadas como tal. Não é necessário
copiar o código para este repositório. Os links não indicam certificação de
correção, segurança ou conclusão pelo clube. Cada implementação mantém sua
autoria e licença próprias; adicionar um link não aplica MIT ao código externo.
